# 9. Веб-приложение PriceLens

4 ноября 2026 года · версия приложения 0.4.0.

Владелец продукта выбрал SPA с возможностями PWA и GitHub Pages. Нативная разработка приостановлена. Этот документ задаёт текущую архитектуру и заменяет платформенные решения первоначального Flutter-проекта. Правила цен и денежных расчётов из документа 3 используются в браузерной версии.

## Устройство приложения

Исходники находятся в `webapp/`. TypeScript, Vite и CSS формируют статическую сборку. Основной интерфейс содержит сканер, историю и настройки с hash-навигацией. На широком экране результат находится справа от камеры, на узком под ней. Распознанная область выделяется на видео. Русский язык интерфейса сохранён как рабочее допущение прототипа.

| Файл | Ответственность |
|---|---|
| `src/domain.ts` | Разбор и стабилизация цены, целые баны, BigInt и исторический снимок |
| `src/scanner.ts` | MediaDevices, геометрия видимой области, локальный OCR и чтение фотографии |
| `src/storage.ts` | IndexedDB, история, единый снимок курсов и настройки |
| `src/rates.ts` | Проверка ответа ExchangeRate-API и период обновления |
| `src/main.ts` | Экраны, разрешения, последовательная запись истории, PWA и установка |
| `scripts/prepare.mjs` | Копирование зафиксированных npm-версий OCR в статические ресурсы |
| `scripts/build.mjs` | Сборка и Service Worker с хешем содержимого |

## Камера и распознавание

Камера открывается по явному нажатию с `audio: false`. Требуется HTTPS либо localhost. Запрашивается основная камера, доступность фонарика определяется по capabilities. Уход в другой раздел, фон страницы, смена камеры и пауза останавливают медиатреки. Результат завершившегося OCR принимается только для своей сессии.

Tesseract.js 7 использует LSTM-движок WebAssembly в отдельном Worker. Все варианты ядра, выбираемые в зависимости от SIMD, Worker и английская модель с латиницей включены в сборку. Запросов к CDN для OCR нет. Полный текст и изображения не записываются в историю. Выбор фотографии добавлен как браузерный способ прочитать отдельный ценник при недоступной камере. Результат фотографии требует подтверждения.

Кадр обрезается по видимой рамке с учётом `object-fit: cover`. В обработке находится один кадр. Следующий запрос начинается через 400 мс после завершения предыдущего. Два согласованных наблюдения дают стабильную цену. Для браузерного прототипа окно потери установлено в 3 секунды вместо начального предложения в 1 секунду, чтобы учитывать время WebAssembly OCR. Это допущение нужно проверить на телефоне. Старые и условные цены определяются по тексту. Зачёркивание и дробные цифры другого размера требуют проверки на реальном материале.

Стабильное событие записывается автоматически. Повторные кадры сохраняют идентичность события. Исправление и фиксация используют тот же идентификатор записи. Длительная потеря или другая область ценника начинает новое событие даже при одинаковой сумме.

## Курсы и данные

Используется `https://open.er-api.com/v6/latest/RON` без API-ключа. Проверяются база RON, значение RON=1, положительные EUR/UAH, время данных и следующего обновления. Снимок сохраняется атомарно. Коэффициенты используются как десятичные строки, окончательное округление выполняется half-up через BigInt. При недоступном первом курсе показывается только RON.

Автоматическое обновление учитывает следующую публикацию и часовой интервал между попытками, включая неудачные. Ручной запрос имеет тайм-аут 10 секунд. Данные старше 24 часов отмечаются устаревшими. Зафиксированный результат и история сохраняют свой снимок. История без курса не дополняется задним числом.

Имя базы IndexedDB учитывает путь сайта. В ней находятся `state` и `history`. Транзакция сохранения одновременно ограничивает историю последними 100 записями. Очистка истории сохраняет настройки и курсы. Суммы и коэффициенты независимы от настроек отображения. Очистка данных сайта удаляет локальную историю. Несколько приложений на одном origin не изолированы друг от друга средствами безопасности браузера.

## Офлайн-режим и обновление

Production-сборка генерирует `sw.js`, который при установке загружает все статические файлы и OCR-модели. Надпись «Готово офлайн» появляется после активации Service Worker. До завершения первой загрузки офлайн-запуск не обещается. Курсы загружаются отдельно в IndexedDB. Запросы API не обслуживаются кэшем статических файлов.

Кэш имеет префикс с полным scope и версию по хешу содержимого. Активация удаляет только старые кэши этого приложения. Обновление ожидает завершения текущей сессии либо нажатия «Обновить». Перед принудительной активацией интерфейс останавливает камеру и дожидается записи данных. Dev-сервер Service Worker не регистрирует.

В manifest заданы относительные start URL, scope и иконки 192/512. Браузер с install prompt показывает кнопку установки в настройках. Для Safari приведён способ добавления на главный экран. Установка и камера на физических устройствах входят в приёмку.

## Размещение и проверка

`npm ci`, `npm test` и `npm run build` готовят приложение. Для Pages проекта используется `PAGES_BASE=/PriceLens/`. Каталог `dist` содержит статические файлы. Пользовательские данные остаются в браузере. Приватность исходников и доступ к сайту настраиваются отдельно.

Первоначально репозиторий создан приватным. GitHub ответил, что текущий тариф не поддерживает Pages для этого приватного репозитория. Владелец явно разрешил в таком случае сделать репозиторий публичным. Это изменение выполнено, Pages настроен на GitHub Actions. Workflow публикации выполняет тесты и сборку, затем публикует изменения `webapp/` из `main`. Доступен и ручной запуск.

Проверки логики находятся в `tests/domain.test.ts`, браузерные сценарии в `tests/browser/app.spec.ts`. В них используются тестовые курсы. Офлайн-OCR запускается настоящим Tesseract на созданном ценнике после перезагрузки без сети. Камера проверяется виртуальным видеоустройством. Приёмка включает реальные Android/iPhone и сложные ценники.
