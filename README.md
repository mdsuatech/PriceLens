# PriceLens

PriceLens помогает покупать в Румынии. Наведите камеру на ценник в RON / LEI, чтобы увидеть сумму в EUR и UAH.

**[Открыть PriceLens](https://yradov.github.io/PriceLens/)**

С 4 ноября 2026 года основной вариант приложения — **SPA/PWA на TypeScript с размещением на GitHub Pages**. Нативная разработка приостановлена по решению владельца продукта. Исходники Flutter сохранены как предыдущий прототип. Версия веб-приложения **0.4.0**.

Исходники находятся в [публичном репозитории GitHub](https://github.com/yradov/PriceLens). Репозиторий сделан публичным по поручению владельца после подтверждения, что текущий тариф не поддерживает Pages для приватного репозитория.

## Запуск

Нужен Node.js 24 LTS и npm.

```powershell
cd webapp
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Камера включается с разрешения пользователя. В разработке работает localhost, на телефоне нужен сайт по HTTPS. Адрес компьютера вида `http://192.168…` не предоставляет безопасный контекст камеры.

Доступны непрерывный сканер, рамка, локальный OCR, загрузка фотографии ценника, ручной ввод, выбор неоднозначной цены, исправление, фиксация, история последних 100 событий, порядок и видимость валют, округление до 0 или 2 знаков, загрузка и кэширование реальных курсов. Доступность фонарика зависит от камеры и браузера.

На первом открытии готовой сборки дождитесь отметки **«Готово офлайн»**. В кэш сохраняются приложение и файлы OCR, включая модель. После этого доступен запуск без сети. Для первой конвертации нужно отдельно успешно загрузить курсы. В dev-режиме Service Worker отключён, офлайн-работу проверять на production-сборке.

Кадры обрабатываются на устройстве, выбранное фото остаётся в памяти страницы. IndexedDB хранит суммы, курсы, историю и настройки без снимков. История относится к конкретному браузеру и адресу сайта. Очистка данных сайта удаляет записи.

## Проверки и сборка

```powershell
cd webapp
npm test
npm run check
$env:PAGES_BASE = '/PriceLens/'
npm run build
npm run preview
```

Статические файлы находятся в `webapp/dist`. OCR обслуживается тем же сайтом. Для GitHub Pages репозитория PriceLens нужен `PAGES_BASE=/PriceLens/`, для корня собственного домена использовать `/`. Навигация использует `#scan`, `#history`, `#settings`.

Для браузерных проверок установить Chromium командой `npx playwright install chromium`, затем выполнить `npm run test:browser`. Чтобы использовать имеющийся Chrome, задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE` полным путём к исполняемому файлу. Тесты используют сборку с `PAGES_BASE=/PriceLens/`, порт 4178, тестовые курсы и виртуальную камеру. Отдельный сценарий запускает настоящий Tesseract на созданном ценнике с отключённой сетью.

## GitHub Pages

Workflow `Check browser application` проверяет приложение при push и pull request, затем сохраняет сборку в артефактах Actions. Workflow `Publish PWA to GitHub Pages` выполняет проверки и публикует сайт при изменениях `webapp/` в ветке `main`. Он также запускается вручную. Pages настроен на GitHub Actions. Публичность сайта и репозитория проверяется отдельно.
